# 訂金管理系統（deposit-manager）

以 Google 試算表＋Apps Script 網頁程式管理店面訂金，取代現行的「客注品精算確認リスト」Excel。

- 設計書：[`docs/design.html`](docs/design.html)（架構、技術選擇、資料設計、流程、實施計畫、待確認事項）
- 程式：`src/Code.gs`（後端）、`src/Index.html`（操作畫面）、`src/appsscript.json`
